# 얼마씩 (eolmassik)

> 가입 없이 링크 하나로 끝내는 1/N 정산

여러 명이 함께 쓴 돈을 항목별로 입력하고, 누가 얼마씩 더 낼지 조정한 뒤, 카카오톡으로 공유하는 모바일 웹 서비스입니다.

🔗 **[얼마씩 사용해보기](https://eolmassik.app)**

<br />

## 왜 만들었나

정산할 때 실제로 나오는 말은 "우리 얼마씩 내면 돼?" 입니다. 그런데 이 질문에 답하기가 생각보다 번거롭습니다.

- 카톡에서 암산하면 항목이 3개만 넘어가도 틀립니다
- 기존 정산 앱은 가입·앱 설치·친구추가를 요구합니다. 일회성 정산에는 과합니다
- **"이건 우리가 낼게"** 같은 현실적인 조정이 어느 도구에서도 깔끔하게 처리되지 않습니다

얼마씩은 이 세 가지를 해결하는 데만 집중합니다.

<br />

## 주요 기능

### 불균등 부담을 일급 기능으로

"13,000원 중에 우리가 8,000원 낼게", "바베큐 비용은 우리가 낼게" 같은 조정이 예외 처리가 아니라 기본 기능입니다. 금액을 입력하면 나머지 인원이 각각 얼마를 내게 되는지 실시간으로 보여줍니다.

### 최소 송금 계산

각자의 (결제액 − 부담액)을 구해 채권·채무를 매칭합니다. 6명이면 최대 15건이 나올 송금을 5건 이하로 줄입니다.

### 서버 없는 링크 공유

정산 데이터를 압축해 URL fragment에 인코딩합니다. 데이터베이스도 로그인도 없이 링크 하나로 공유됩니다.

| 참여자 | 항목 | 압축 후 URL |
|---|---|---|
| 5명 | 10개 | 586자 |
| 8명 | 30개 | 1,200자 |
| 12명 | 100개 | 2,831자 |

항목 구조가 반복되므로 항목 수에 대해 선형 이하로 증가합니다. 1,500자를 넘는 경우에만 단축 URL 백엔드로 폴백합니다.

## 시작하기

```bash
pnpm install
pnpm dev
```

카카오 공유 기능을 사용하려면 `.env.local`에 JavaScript 키를 설정합니다.

```bash
VITE_KAKAO_JS_KEY=your_kakao_javascript_key
```

<br />

## 테스트

돈 계산이 1원이라도 틀리면 서비스의 신뢰가 무너지므로, 계산 로직은 단위 테스트로 고정되어 있습니다.

```bash
pnpm test
```

- 항목별 부담액의 합 == 항목 금액
- 전체 부담액의 합 == 전체 결제액의 합
- 추가 부담이 항목 금액을 초과하는 경우
- 전액 부담자가 여러 명인 경우
- 참여자 1명, 금액 0원 등 엣지 케이스

## 프로젝트 구조

```
src/
├─ features/
│  ├─ participants/   참여자 입력, 프리셋
│  ├─ items/          항목 입력, 추가 부담 설정
│  ├─ result/         부담액·송금 계산 결과
│  └─ share/          텍스트 생성, URL 인코딩, 카카오 공유
├─ lib/
│  ├─ calc/           정산 계산 로직 (순수 함수 + 테스트)
│  └─ codec/          URL 인코딩·디코딩 (키 축약 스키마)
├─ routes/            화면 (/ 편집, /s 읽기 전용)
├─ store/             Settlement 전역 상태
├─ constants/         기본 옵션, 임계값
├─ types/             도메인 모델
└─ styles/            디자인 토큰, 전역 스타일
```

계산 로직(`lib/calc`)은 UI에 의존하지 않는 순수 함수로 분리되어 있습니다.
